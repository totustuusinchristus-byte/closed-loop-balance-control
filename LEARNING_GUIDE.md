# Learning guide

Be able to explain inverted-pendulum instability, state variables, proportional and derivative feedback, sensory delay, perturbation response, stability, numerical integration and control effort.

## Exercises
1. Set Kp and Kd to zero and explain the response.
2. Compare delays of 0–200 ms.
3. Compare at least three Kp/Kd combinations.
4. Identify a poorly behaving parameter set and explain why.
5. Describe how vestibular, EMG or motor-unit information could enter a richer model.
6. State clearly why this simulation is not robotics-hardware experience.

Run: `python analysis.py`.
